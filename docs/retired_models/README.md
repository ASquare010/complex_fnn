# Retired model reports

These folders retain results for implementations removed from the active code
during the Curve-Wide cleanup. They are historical evidence, not runnable models.
All compact records and feature-removal evidence remain available. Local source
snapshots and checkpoints remain in ignored `dump/`; they are not shipped by Git.

The reusable shortlist is in [ffn_experiments](../../ffn_experiments/README.md).
Historical recipes are in [study_configs](../study_configs).
The [leaderboards](../leaderboard.md) continue to include all completed models.
